# SQL Learning Journey

I am learning SQL using PostgreSQL and pgAdmin 4, focusing on practical querying, database fundamentals, and interview preparation for Data Analyst, BI Analyst, and Data Engineering roles.

## Environment

- **Database:** PostgreSQL
- **Client:** pgAdmin 4
- **Practice database:** `sql_learning`
